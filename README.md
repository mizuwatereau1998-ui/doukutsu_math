# ポップンの大脱走！

**かけて、わって、とびこえて。** 青いゼリーのポップンと走る、算数学習 × エンドレス逃走アクションの試作版です。

HTML / CSS / JavaScript だけで動きます。パッケージのインストール、ビルド、アカウント、APIキーは不要です。

## まずあそぶ

1. リポジトリのファイルをまとめてダウンロードし、ZIPの場合は展開します。
2. **`index.html` をブラウザで開きます。** 他のファイルは同じフォルダ構成のままにしてください。
3. 小3・小4を選び、「さあ、にげよう！」を押します。

開発時は、リポジトリのフォルダで次のコマンドを実行しても起動できます（Python 3が必要）。

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。終了はターミナルで `Ctrl+C`。Node.jsがある環境では `npm start` でも起動できます。`npm install` は不要です。

スマホは **横向き** にしてください。縦向きにするとゲームを一時停止します。別タブやホーム画面に移ったときも自動で停止します。

## 操作

| 操作 | PC | スマホ |
| --- | --- | --- |
| ジャンプ・上の道へ | 上矢印キー ↑ | 上スワイプ |
| 下の道へ | 下矢印キー ↓ | 下スワイプ |
| 一時停止・再開 | Esc または右上の Ⅱ | 右上の Ⅱ |
| 効果音の切り替え | ページ右上の ♪ | ページ右上の ♪ |

- 自動で走るので、左右の操作はありません。
- 通常時、下段で ↑ を押すと **ジャンプして上段に乗ります**。上段で ↑ を押すとその場でジャンプします。空中での連続ジャンプはできません。
- 穴はジャンプ、上段に垂れ下がる鍾乳石は ↓ で回避します。
- 問題中は ↑ / ↓ で隣の道へ1段ずつ移動します。3択の最上段へは ↑ を2回。キーの押しっぱなしではなく、1回ずつ押してください。
- 短いスワイプでも反応します。1スワイプにつき1段だけ移動します。

## ゲームのルール

- 5回ミスすると追手につかまり、結果画面へ進みます。途中のミスではゲームは止まりません。
- ミス直後は1.2秒間の無敵時間があり、近くの障害物も除かれます。
- 出題は150m、300m、450m…の節目が基準です。表示中は重ねず、通過した複数の節目は1問にまとめます。
- 問題終了後は最低5.5秒のアクション区間を挟みます。そのため、序盤の10秒問題などで次の節目を通過した場合、実際の出題距離は150mより長くなります。直前35m（前問終了後の休止区間がある場合はその終了0.6秒前から）と終了直後0.6秒は障害物を避ける安全区間です。
- 450m以降はコウモリが飛んできます。下段の低いコウモリはジャンプ、上段の高いコウモリは下降で回避します。羽先は当たり判定に含めず、胴体に触れると1ミス。無敵時間も適用します。
- 式が出てから分岐に着くまでに、答えの道を選びます。制限時間終了時の道で自動判定します。問題中は穴や鍾乳石は出ません。
- 通常問題は、正解でそのまま、不正解で1段階後退します。
- 金色にきらめく問題は、正解すると追手から1段階離れます。基本は3問ごと、危険なときは早めに登場します。追手から最も離れているときには出ません。
- 900m以降は3択になります。問題後は最上段から通常の足場に安全に合流します。
- 速度は230px/秒から最大500px/秒へ滑らかに上がります。判断時間は最初の10秒から、3,600mで最短2秒まで短くなります。
- 最高記録は **小3・小4別々** にブラウザのlocalStorageへ、ゲームオーバー時に保存します。ブラウザやアクセス先を変えると別の記録になります。保存が制限されている場合もプレイできます。

### 出題範囲

| 学年 | かけ算 | わり算 | 小数 |
| --- | --- | --- | --- |
| 小3 | 2〜9の九九 | 九九を使う、割り切れるわり算 | 小数第1位までのたし算・ひき算 |
| 小4 | 2桁 × 1〜2桁 | 最大3桁 ÷ 1〜2桁、割り切れるもの | 小数第2位までのたし算・ひき算 |

3種類からランダムに出題します。小数は10倍・100倍した整数で扱い、誤差のある答えや選択肢の重複を防いでいます。余り、分数、筆算の入力は試作版には含みません。

## 難易度を変える

**`js/config.js` の `CONFIG`** に主な設定をまとめています。値を変更し、ブラウザを再読み込みすると反映されます。

| 定数 | 初期値 | 内容 |
| --- | --- | --- |
| `startSpeed` / `maxSpeed` | 230 / 500 | 最初と最大の走行速度（px/秒） |
| `speedGrowthDistance` | 2000 | 速度の上がり方。大きいほど緩やか |
| `questionIntervalMeters` | 150 | 出題の節目となる距離間隔（m） |
| `questionRestSeconds` | 5.5 | 問題終了から次問までに挟む最低アクション時間（秒） |
| `questionSafetyMeters` | 35 | 次の出題直前に障害物を除く距離（m） |
| `questionSafetySeconds` | 0.6 | 問題前後の安全時間（秒） |
| `batStartDistance` | 450 | コウモリが登場し始める距離（m） |
| `batChanceMax` | 0.36 | 後半のコウモリの最大生成確率 |
| `batSpeedFactor` | 1.08 | コウモリの接近速度倍率 |
| `obstacleMinEncounterGap` | 1.6 | 前の障害物通過から次の接近までの最低間隔（秒） |
| `questionTimeMax` / `questionTimeMin` | 10 / 2 | 最長・最短の判断時間（秒） |
| `shortestTimeDistance` | 3600 | 判断時間が最短になる距離（m） |
| `threeChoiceDistance` | 900 | 3択に切り替わる距離（m） |
| `obstacleIntervalStart` / `obstacleIntervalEnd` | 3.5 / 1.8 | 序盤・後半の障害物間隔（秒）。最大0.6秒のばらつきが加わる |
| `specialEvery` | 3 | 特別問題が出る基本の問題数間隔 |
| `dangerSpecialAt` | 3 | 特別問題を早めるミス数 |
| `maxMisses` | 5 | つかまるまでのミス数（画面のゲージも変更が必要） |
| `invincibleSeconds` | 1.2 | ミス直後の無敵時間（秒） |

速度、ジャンプ、障害物の間隔を大きく変えると避けられない配置ができることがあります。変更後はテストと実際のプレイを行ってください。障害物の種類や穴の幅は `js/obstacles.js`、出題範囲は `js/math.js` で調整します。

## 前作のキャラクター素材に差し替える

今は、Canvasで描く青いゼリーとモンスターを使用しています。洞窟や結晶もすべて図形のため、画像の用意は不要です。

1. 次のPNGを `assets/characters/` に置きます。
   - `pop_idle.png`（通常）
   - `pop_correct.png`（正解時）
   - `pop_chain2.png`（2連続正解時）
   - `pop_chain3.png`（3連続以上の正解時）
2. `js/config.js` の `useCharacterImages: false` を **`true`** にします。
3. ブラウザを再読み込みします。

透過背景の正方形に近い画像を推奨します。見つからない表情は通常画像へ、通常画像がなければ図形キャラクターへフォールバックします。大きさや位置は `renderer.js` の `pop()` で調整できます。

## GitHub Pagesで公開する

1. 変更したファイルをGitHubのリポジトリへコミット・プッシュします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Deploy from a branch** を選び、`main` ブランチの **`/ (root)`** を指定して保存します。
4. 配信完了後にPagesが表示するURLを開きます。

相対パスなので、リポジトリ名が付くURLでも動きます。公開作業は自動では行っていません。

## 走行アニメーションと背景

`js/renderer.js` の `Visual` に見た目の設定をまとめています。`stride` は1回弾むまでに進む距離（px）で、小さくすると弾むテンポが速くなります。実際の走行距離から周期を求めるため、ゲームの加速・停止にそのまま連動します。着地の潰れ、前傾、ジャンプ・下降・転倒の姿勢は図形とPNGに共通です。端末で「視差効果を減らす」等を有効にすると、追加の弾みや速度線を抑えます。

以前は足場が画面上に固定され、模様・結晶・支柱だけが別々に流れていたため、動く歩道のように見えていました。現在は岩盤と装飾を同じ世界座標から描き、穴の位置も含めて一体で移動します。`Visual.parallax` の遠景・中景・近景・足元・最前景の倍率で奥行きを表現しています。カメラの基準位置と衝突面は従来通りで、描画の弾みや傾きは物理計算には反映しません。

追手も距離に連動して腕と足を交互に振り、前傾して上下に弾みます。ミスが増えると振幅や表情が強まり、ミス直後は短い突進を行います。追跡ゲージやゲームオーバーの判定には使わない描画上の動きです。コウモリの羽ばたきと上下の揺れもCanvasで描き、上下の揺れは当たり判定にも共通の座標を使っています。

## 動作確認

Node.js 18以上があれば、追加のインストールなしで実行できます。

```sh
npm run check
npm test
```

自動テストは33項目です。学年×選択肢数ごとに5,000問（合計20,000問）の計算と答えの一意性、上下移動、最大速度でのジャンプ、当たり判定、無敵時間、2択・3択、正解・不正解・回復、10秒→2秒の判断時間、一時停止、4パターンの3分間の走行を検証します。描画についても、走行・空中・転倒の姿勢、岩盤と模様の同期、PNGへの共通変形、描画によってゲーム状態が変わらないことを検証します。追加で距離基準の出題と安全区間、コウモリの上下の高さ・無敵・低速/高速での回避、最大速度付近での4パターンの90秒間の混合配置、敵の迫り方を確認します。

追加の `tests/browser_smoke.py` は、PythonのPlaywrightとChromiumがある環境で使えます。HTTPサーバーを起動してから `python3 tests/browser_smoke.py` を実行してください。環境に応じて `CHROMIUM_PATH` を指定します。ゲーム自体にはPlaywrightは不要です。

今回の環境では、HTTP経由のChromiumでPC操作、スマホのタッチ操作を再現して確認しています。**実機のiPhone Safari / Android Chromeは未確認**です。ローカルファイルの直接起動も、このクラウドのブラウザ管理ポリシーが `file://` を禁止しているため未確認です。直接開けない環境では上記のHTTPサーバー方式を使用してください。次の点を試してみてください。

- ↑のジャンプ・上段移動、↓の下降が自然にできるか。
- スマホ横向きで短いスワイプが反応し、画面がスクロールしないか。
- 上段の穴をジャンプで、鍾乳石を下降で避けられるか。
- 450m以降の低いコウモリをジャンプ、高いコウモリを下降で避けられるか。
- ミスした直後の敵の突進、危険時の表情、加速に合わせた手足の動きが自然か。
- 150mの節目と、問題が長引いた場合の遅延・安全区間が自然か。
- 2択・3択で選んだ数字と正誤判定が一致するか。
- 金色の問題に正解すると、追手との距離ゲージが1段階戻るか。
- 5回ミスした結果画面、再挑戦、学年選択への移動ができるか。
- 再読み込み後も、学年ごとの最高記録が残っているか。

## 試作版の範囲

キャラクターと背景は仮の図形イラスト、効果音はブラウザで合成した短い音です。ステージは安全な間隔で障害物をランダムに生成する基本構成で、専用の複雑なステージパターンやBGMはまだありません。小学1・2・5・6年生は「準備中」です。まずはプレイして、速さ、問題の間隔、スワイプの感触を調整できる構成にしています。
