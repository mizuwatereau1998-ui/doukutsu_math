# 3段構成の配置・回避検証

再実行: `npm test` と `node tests/advanced-patterns.mjs`。ブラウザ操作はHTTPサーバー起動後に `python3 tests/browser_smoke.py`。

全360配置について、各波が通過する際に実際の衝突関数で2段を同時にふさぎ、3段すべてはふさがないことを確認した。探索結果の入力列を1/120秒刻みの物理で再生し、すべて無衝突で通過した。各距離帯で上・中・下段の接地を確認。3波以上の配置では2回以上の入力を要することも検査している。穴はジャンプで回避できるため、「安全段」は地上での安全性を指し、空中で別経路を通れる場合がある。

各距離帯の開始点から4シード×90秒、合計16走行（24分相当）をGame.updateで実行。算数出題、正解操作、生成待ち、既存障害物との組み合わせも通した。全走行でミス0、生成失敗0。開始距離帯を超えて走るため、この長時間走行の数値を距離帯内だけの分布とは扱わない。

生成から次の生成までの時間には連続波の通過時間と算数問題の判断時間を含む。全走行で、算数中を除く上記の空白は5.5秒未満であり、生成失敗による空白は起きなかった。詳細なシード別結果は [advanced-validation.json](advanced-validation.json)。

900m未満は変更前のソースと同一入力の300配置（0・450・899m×100シード）を比較し、生成物が完全一致した。既存のPC操作・スマホタッチのブラウザスモークも成功。file://の直接起動は管理ポリシーでスキップ。実機スマホの操作感・主観的な難易度は今回の自動検証の対象外。

経路探索は待機・上下入力を0.15秒間隔で分岐させ、加速・クモの降下・コウモリの速度・ジャンプ・落下を固定ステップで評価する。状態を量子化して重複を減らすが、保持する実状態は丸めない。上限120状態・30秒の探索なので全ての可能な経路を網羅するものではなく、存在する経路を見つけられず不採用にする可能性は残る。採用には実際に通過する経路が必要。全段封鎖の拒否と、入力・既存障害物を変更しないこともテストした。
